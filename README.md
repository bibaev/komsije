# Komšije — куда зайти, чтобы поддержать соседей

> «Komšije» по-сербски — «соседи»; заголовок сайта «Svrati kod komšija» — «зайди к соседям».

Список с тегами и карта бизнесов в Белграде и Нови-Саде, у которых были счета в Alta banka, поверх проверенной таблицы сербской инициативы «Zajedno uz ruske biznise». Для тех, кто хочет поддержать обычной покупкой и ищет, что рядом.

Сайт — [komsije.cherdak.rs](https://komsije.cherdak.rs). Откуда проект и на каких принципах держится — [docs/origin.md](docs/origin.md), бренд — [brand/style-guide.md](brand/style-guide.md).

## Данные

Источник правды — [таблица инициативы](https://docs.google.com/spreadsheets/d/1IBRo4Frwh6ph5q1Bykk8JeNIzJwntW5JVyS1YGQXJCE/htmlview), вкладка «Verifikovani biznisi». **Добавить бизнес или исправить адрес — в таблице, не PR-ом**: сайт её только читает.

Сборка (`python -m komsije.build`) скачивает таблицу и:
- раскладывает ячейки с несколькими адресами по точкам; строку без названия считает ещё одной точкой предыдущего бизнеса;
- берёт координаты из ссылок Google Maps (`!3d…!4d…`). Ссылка «поделиться» с телефона и список мест координат не дают: точку для такого адреса ставят руками в `data/overrides.json` (`points`, ключ — адрес дословно, как в таблице). Адрес без точки попадает в список с кнопкой «Маршрут», но не на карту: неправильная точка хуже, чем никакая;
- понимает ссылки, записанные хендлом или голым доменом («@askona_serbia», «reparo.rs», «t.me/…»), чистит их от `utm_*`, `fbclid` и подобного; в страницу попадают только `http(s)`;
- кладёт рядом со страницей `b/<имя-номер>/` для каждого бизнеса: ссылка «Поделиться» с превью в мессенджерах, она открывает сайт ровно на этом бизнесе.

| Файл | Что в нём |
|---|---|
| `config.json` | id таблицы, проверенной вкладки и вкладки заявок, ссылка на инициативу и ее автора; контакт и репозиторий для подвала; адрес сайта для превью; источник тайлов карты |
| `data/categories.json` | категории: подписи ru/sr, правила автотегов по полю `Delatnost`; значок — `brand/icons.svg` с тем же id |
| `data/overrides.json` | слой обогащения по MB или ПИБ: имя без юрформы, категории, теги, описание на русском, на сербском — если в таблице записано криво, точки для адресов, которые ссылка не даёт (`points`), адреса, для которых точку искали и не нашли (`no_point`) |
| `data/geocache.json` | ссылка → координаты для ссылок из текущей таблицы, пишет сборка |
| `site/` | статика: `index.html`, `app.js`, `style.css`; `data.js`, `b/`, `icons.svg`, `favicon.svg` пишет сборка |
| `brand/` | бренд v1 «Улица»: `tokens.yml`, `icons.svg`, `favicon.svg`, правила — `style-guide.md` |

Бизнес без записи в `overrides.json` получает категории по ключевым словам и описание из таблицы, сборка покажет его в предупреждениях. Что осталось обогатить — `python -m komsije.todo`, с флагом `--geocode` еще и с точками-кандидатами из OpenStreetMap: «надежно» — только тот же номер дома в границах города. Порядок работы — [`.claude/commands/enrich.md`](.claude/commands/enrich.md), его же можно читать как инструкцию без Claude.

На странице над списком — плашка «Откуда список»: чья таблица, как добавить свой бизнес и точное время последней сверки. Частоту обновления не обещаем: сверка идёт так часто, как получается, а время видно всем.

## Запуск

```bash
python3.12 -m venv .venv && .venv/bin/pip install -e ".[dev]"
.venv/bin/python -m komsije.build           # только stdlib, ставить нечего
python3 -m http.server -d site 8000         # http://localhost:8000
.venv/bin/pytest -q && .venv/bin/ruff check .
```

Через `file://` тайлы OSM могут не загрузиться: им нужен Referer.

## Публикация

Сайт живёт на GitHub Pages, публикует его `.github/workflows/pages.yml`: проверки, сборка из свежей таблицы, деплой. Поэтому публикация — это и сверка с таблицей. Запускается на merge в `main` и вручную: Actions → Publish → Run workflow или `gh workflow run pages.yml`. Расписание включается строкой `schedule` в том же файле.

Если сборка упала, на сайте остаётся прошлая версия. Сборка падает и тогда, когда бизнесов стало на треть меньше прошлой публикации: скорее всего, таблицу перестроили. Если сокращение настоящее, запускайте вручную с галкой «force». Адреса без точки и бизнесы без обогащения попадают в сводку запуска.

PR проверяет `.github/workflows/checks.yml`: тесты, линтер и пробная сборка. Он ничего не публикует.

## Помочь

- **Бизнес, адрес, контакты** → вкладка «NOVI UNOSI – PENDING VERIFIKACIJA» в таблице.
- **Неверная точка, категория, ошибка карты** → [issue](../../issues/new/choose) по шаблону или в Telegram [@v_bibaev](https://t.me/v_bibaev).
- **Точки для адресов без координат, теги и описания** → PR в `data/overrides.json`; что осталось сделать, показывает `python -m komsije.todo --geocode`.
- **Код** → PR; правила и инварианты — [CLAUDE.md](CLAUDE.md).
